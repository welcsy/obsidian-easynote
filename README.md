# EasyNote — Obsidian 手繪筆記插件

在 Obsidian 側邊欄開啟一個全功能的手繪畫布，支援多色畫筆、文字圖層、圖片圖層，並可將成果儲存為 PNG 到 Vault。

---

## 功能特色

### 畫布與縮放
- 可自訂畫布尺寸（預設自動填滿面板，支援 1920×1080、3840×2160 等快速預設）
- 滑鼠滾輪縮放（以游標位置為錨點，Canva 風格）
- 中鍵按住拖曳平移畫布
- 按 `0` 重設縮放至 100%

### 圖層順序（由上到下）
| 層級 | 說明 |
|------|------|
| 繪畫層 | 手繪筆觸（透明底，最頂層） |
| 文字層 | 可移動的文字方塊 |
| 圖片層 | 載入的圖片（最底層） |

### 畫筆工具
- 5 種預設顏色（黑、紅、藍、綠、橘）
- 雙擊顏色按鈕 → 開啟 sRGB 顏色選擇器自訂顏色
- 筆刷大小滑桿（1–60）
- 透明度滑桿（1%–100%）
- 橡皮擦（`destination-out` 透明擦除，不影響圖片層）

### 文字工具
- 工具列按鈕「文字 (T)」或快捷鍵 `T` 切換
- 點擊畫布任意位置 → 彈出浮動輸入框
- 點擊已有文字 → 開啟編輯（支援多行）
- 選取模式下雙擊文字 → 重新編輯
- 選取模式下單擊文字 → 可拖移位置
- 字體大小輸入框（8–200px），即時套用至選取中的文字
- `Escape` 取消編輯，清空內容後提交將刪除該文字圖層

### 圖片圖層
- **載入圖片**：本機檔案選擇、拖曳到畫布、Ctrl+V 貼上
- **Vault 圖片**：在左側資料夾側欄瀏覽，側欄可按資料夾篩選，右側縮圖預覽後點選
- 選取模式（`S`）下可拖移、縮放（四角控點）
- 按住 Shift 拖動控點 → 等比例縮放
- `Delete` 刪除選取的圖片或文字圖層

### 儲存
- 「儲存 PNG」按鈕將三層合成（圖片 → 文字 → 繪畫）輸出為 PNG
- 儲存到 Vault 的 `EasyNote/` 資料夾（可在插件設定中修改）
- 檔名格式：`EasyNote-YYYY-MM-DDTHH-MM-SS.png`

## 快捷鍵

| 鍵 | 功能 |
|----|------|
| `1`–`5` | 切換畫筆顏色 |
| `E` | 切換橡皮擦 |
| `S` | 切換選取工具 |
| `T` | 切換文字工具 |
| `C` | 清除畫布（繪畫層 + 文字層 + 圖片層） |
| `Delete` | 刪除選取的圖片或文字 |
| `+` / `-` | 筆刷大小 ±2 |
| `0` | 重設縮放至 100% |
| 滾輪 | 縮放畫布 |
| 中鍵拖曳 | 平移畫布 |
| `Ctrl+V` | 貼上剪貼簿圖片 |

## 安裝

### 手動安裝
1. 前往 [Releases](../../releases) 下載最新版本的 `main.js`、`manifest.json`、`styles.css`
2. 在 Vault 的 `.obsidian/plugins/easynote/` 資料夾中放置這三個檔案
3. 在 Obsidian 設定 → 社群插件 中啟用 **Easy Note**

### 從原始碼建置
```bash
git clone <repo-url>
cd godot-easynote
npm install
npm run build
```
將產出的 `main.js`、`manifest.json`、`styles.css` 複製到 Vault 插件資料夾。

## 設定

在 Obsidian 設定 → Easy Note 中可調整：

| 設定 | 說明 | 預設值 |
|------|------|--------|
| 預設畫筆顏色 | 啟動時的顏色索引（0–4） | `0`（黑色） |
| 預設筆刷大小 | 啟動時的筆刷粗細 | `6` |
| 儲存資料夾 | PNG 儲存目的地（Vault 相對路徑） | `EasyNote` |

---

## 開啟插件

- Ribbon 圖示：左側欄的鉛筆圖示
- 命令面板（Ctrl+P）：搜尋「開啟 EasyNote 手繪筆記」

---

## 系統需求

- Obsidian `1.0.0` 以上
- 僅限桌面版（Desktop Only）
