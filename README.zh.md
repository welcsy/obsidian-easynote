# EasyNote — Obsidian 手繪筆記插件

在 Obsidian 側邊欄開啟全功能手繪畫布，支援多色畫筆、橡皮擦、圖片圖層（含多選圈選）、文字圖層、Markdown 圖層（支援 `[[wikilink]]` 與 `[text](url)` 超連結），以及可命名的復原 / 重做歷程。畫布狀態以 `.enote` 格式儲存，可隨時繼續編輯。

---

## 功能特色

### 插畫工具
- **多色畫筆**：5 色快速切換（快捷鍵 `1`–`5`），長按色塊可自訂顏色
- **橡皮擦**（快捷鍵 `E`）：
  - **單點模式**：`destination-out` 透明擦除，不影響圖片層
  - **圖片模式**：點選即刪除對應筆觸圖層
- **筆刷大小**：7 階模式或連續 1–60px 模式（可在設定切換），拉動滑桿即時顯示數值
- **透明度**：1%–100% 可調
- **筆刷模式**：
  - **單點模式**：每一筆直接畫在繪畫層（傳統像素繪製）
  - **圖片模式**（預設）：每一筆畫完後自動成為可選取 / 刪除的圖片圖層
- **繪畫選取**（快捷鍵 `M`，僅限單點模式）：框選繪畫層區塊，可移動、縮放後合併回繪畫層

### 圖片與圖層工具
- **選取工具**（快捷鍵 `S`）：
  - 單點選取 → 移動、四角縮放（`Shift` = 等比例）、`Del` 刪除
  - **拖曳圈選**：在空白處拖曳畫出選框，框住的圖片 / 文字 / Markdown 圖層形成群組（紫色邊框），可整體移動、縮放、`Del` 一次刪除
- **載入本機圖片**：本機檔案選擇，或拖曳 / `Ctrl+V` 貼上
- **載入 Obsidian 圖片**：從 Vault 中瀏覽並選取圖片

### 文字工具
- **文字圖層**（快捷鍵 `T`）：點擊畫布新增，雙擊現有文字編輯
- **Markdown 圖層**：以「載入筆記」載入 Vault `.md` 檔並即時渲染；雙向同步；雙擊編輯
  - 支援 `[[wikilink]]` — 點擊在 Obsidian 開啟對應筆記
  - 支援 `[text](url)` — 點擊在瀏覽器開啟外部連結

### 復原 / 重做
- **Ctrl+Z / Ctrl+Y**：復原 / 重做，最多 50 步
- **下拉歷程選單**：點擊 ↩ / ↪ 按鈕旁的箭頭展開歷程，列出每步操作名稱，可直接跳轉至任意步驟

### 畫布管理
- **儲存畫布 / 載入畫布**：以 `.enote` 儲存完整專案，可在 Vault 中管理多個畫布
- **匯出**：將所有圖層合成後匯出為 PNG / JPEG / WebP 到 Vault；自動帶入上次儲存 / 載入的專案名稱
- **畫布大小**：可自由調整，預設 1920×1080
- **縮放 & 平移**：滾輪縮放（游標錨點）、中鍵拖曳平移；`0` 重設至 100%

### 觸控支援
- **雙指縮放 / 平移**：標準 pinch-to-zoom 手勢
- **長按**：觸發右鍵選單（上下文選單）
- **手寫筆**：Pointer Events 原生支援

## 圖層順序（由上到下渲染）

| 層級 | 說明 |
|---|---|
| 繪畫層 | 手繪筆觸（單點模式）或筆觸圖層群（圖片模式） |
| Markdown 圖層 | Vault 筆記渲染結果 |
| 文字層 | 可移動的文字方塊 |
| 圖片層 | 載入的圖片（最底層） |

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `1`–`5` | 切換畫筆顏色 |
| `E` | 切換橡皮擦 |
| `T` | 文字工具 |
| `S` | 選取工具（含拖曳多選） |
| `M` | 繪畫選取工具（僅限單點模式） |
| `+` / `-` | 增大 / 減小筆刷 |
| `0` | 重設縮放至 100% |
| `Ctrl+Z` | 復原 |
| `Ctrl+Y` | 重做 |
| `Ctrl+C` | 複製選取圖層 |
| `Ctrl+X` | 剪下選取圖層 |
| `Ctrl+V` | 貼上（內部剪貼板或系統圖片） |
| `Del` | 刪除選取圖層 / 群組 |
| `Esc` | 取消圈選框 / 解除群組選取 |
| 滾輪 | 縮放畫布 |
| 中鍵拖曳 | 平移畫布 |

## 設定說明

| 設定項目 | 說明 | 預設 |
|---|---|---|
| 介面語言 | 繁體中文 / English | 繁體中文 |
| 預設顏色 | 開啟時的預設畫筆顏色 | 黑色 |
| 筆刷模式 | 單點模式（像素繪畫）或圖片模式（每筆成為圖層） | 圖片模式 |
| 筆刷大小模式 | 7 階固定檔位 或 連續 1–60px | 7 階 |
| 預設筆刷大小 | 開啟時的預設筆刷大小 | 第 2 階（6px） |
| 預設五色筆顏色 | 自訂 5 個色塊的起始顏色 | 黑紅藍綠橘 |
| 啟動畫布模式 | 呈現新畫布（預設）或打開前一次 | 呈現新畫布 |
| 預設畫布寬度 / 高度 | 新畫布的初始尺寸 | 1920 × 1080 |
| 繪畫解析度倍率 | 1.0 = 全解析度；0.5 = 效能模式 | 1.0 |
| 時區 | 匯出檔名時間戳用的 IANA 時區 | Asia/Taipei |
| 自動同步 | 定時從 Vault 重新載入 `.enote` | 關閉 |
| 定時自動儲存 | 定時自動儲存到 `.enote` | 關閉 |
| 儲存資料夾 | 匯出 PNG 及儲存 `.enote` 的位置 | `EasyNote` |
| Google Drive 同步 | 連接 Google Drive 以備份 / 同步 | 關閉 |

## .enote 檔案格式

`.enote` 是 EasyNote 的專案格式，保存畫布尺寸、繪畫層、圖片圖層、文字圖層與 Markdown 圖層的完整狀態。

### 在 Obsidian 檔案總管中顯示 .enote 檔

Obsidian 預設會隱藏未知副檔名的檔案。若要讓 `.enote` 出現在左側檔案總管，請開啟：

> **Settings → Files & Links → Detect all file extensions → 開啟**

開啟後，`.enote` 即會正常列於檔案總管，也可透過「載入畫布」按鈕從 Vault 中選取。

## 安裝

### 手動安裝
1. 前往 [Releases](../../releases) 下載最新版的 `main.js`、`manifest.json`、`styles.css`
2. 複製到 Vault 的 `.obsidian/plugins/easynote/` 資料夾
3. 在 Obsidian 設定 → 社群插件 中啟用 **Easy Note**

### 從原始碼建置
```bash
git clone <repo-url>
cd easynote
npm install
npm run build
```
