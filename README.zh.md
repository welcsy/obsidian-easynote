
# EasyNote — Obsidian 手繪筆記插件

> **平台支援：** Windows、Android 完整支援。macOS、iOS、Linux 未經完整測試。

EasyNote 是一款強大的多語言 Obsidian 側邊欄繪圖畫布插件。支援多色畫筆、橡皮擦、圖片圖層（含多選）、文字圖層、Markdown 圖層（`[[wikilink]]`、`[text](url)`）、命名復原/重做、手掌工具（Pan）、i18n 等。畫布狀態以 `.enote` 儲存，隨時可繼續編輯。

---

## 功能特色

### 插畫與畫布工具
- **多色畫筆**：5 色（`1`–`5`），長按色塊自訂顏色
- **橡皮擦**（`E`）：
  - **單點模式**：透明擦除（不影響圖片層）
  - **圖片模式**：點選刪除筆觸圖層
- **筆刷大小**：7 階或連續（1–60px），即時滑桿
- **透明度**：1%–100%
- **筆刷模式**：
  - **單點模式**：直接畫在繪畫層
  - **圖片模式**（預設）：每筆成為可選取圖層
- **繪畫選取**（`M`，僅單點模式）：框選、移動/縮放/合併
- **手掌工具（Pan）**：中鍵拖曳或工具列切換，移動畫布

### 圖層與選取工具
- **選取工具**（`S`）：
  - 點擊 → 移動/縮放，`Del` 刪除
  - **圈選**：拖曳群組選取圖片/文字/Markdown 圖層
- **多選群組**：可整體移動、縮放、旋轉、刪除
- **載入圖片**：檔案選擇、拖曳、`Ctrl+V` 貼上
- **載入 Vault 圖片**：從 Vault 選取

### 文字與 Markdown
- **文字圖層**（`T`）：點擊新增，雙擊編輯
- **Markdown 圖層**：載入 Vault `.md` 檔即時渲染、雙向同步、雙擊編輯
  - `[[wikilink]]` — 點擊在 Obsidian 開啟（**選取/手掌模式皆可**）
  - `[text](url)` — 點擊於瀏覽器開啟

### 復原 / 重做與歷程
- **復原/重做**：`Ctrl+Z` / `Ctrl+Y`，最多 50 步
- **歷程下拉**：可依名稱跳轉任意步

### 畫布管理
- **儲存/載入畫布**：`.enote` 格式，管理多個畫布
- **匯出**：合併所有圖層匯出 PNG/JPEG/WebP
- **畫布大小**：可調整，預設 1920×1080
- **縮放 & 平移**：滾輪縮放（游標錨點）、手掌工具/中鍵拖曳平移，`0` 重設

### 觸控與手寫筆
- **雙指縮放/平移**：標準手勢
- **長按**：觸發選單
- **手寫筆**：Pointer Events 原生支援

### 多語言（i18n）
- **語言**：英文（預設）、繁體中文、簡體中文、日文、韓文
- **可於設定切換語言**

## 圖層渲染順序

| 層級            | 說明                       |
|----------------|----------------------------|
| 繪畫層         | 筆觸（單點/圖片模式）       |
| Markdown 圖層  | Vault 筆記渲染             |
| 文字層         | 可移動文字方塊             |
| 圖片層         | 載入圖片（最底層）         |

## 快捷鍵

| 按鍵           | 功能                       |
|----------------|----------------------------|
| `1`–`5`        | 切換畫筆顏色               |
| `E`            | 切換橡皮擦                 |
| `T`            | 文字工具                   |
| `S`            | 選取工具（含多選）         |
| `M`            | 繪畫選取（僅單點模式）     |
| `+` / `-`      | 增大/減小筆刷              |
| `0`            | 重設縮放至 100%            |
| `Ctrl+Z`       | 復原                       |
| `Ctrl+Y`       | 重做                       |
| `Ctrl+C`       | 複製選取圖層               |
| `Ctrl+X`       | 剪下選取圖層               |
| `Ctrl+V`       | 貼上（內部剪貼板或圖片）   |
| `Del`          | 刪除選取圖層/群組          |
| `Esc`          | 取消選取/解除群組          |
| 滾輪           | 縮放畫布                   |
| 中鍵拖曳       | 平移畫布                   |

## 設定說明

| 設定項目            | 說明                                   | 預設         |
|---------------------|----------------------------------------|--------------|
| 介面語言            | 英文、繁中、簡中、日文、韓文           | 英文         |
| 預設顏色            | 開啟時的畫筆顏色                       | 黑色         |
| 筆刷模式            | 單點（直接繪製）或圖片（每筆成圖層）   | 圖片         |
| 筆刷大小模式        | 7 階或連續 1–60px                      | 7 階         |
| 預設筆刷大小        | 開啟時的筆刷大小                       | 第 2 階（6px）|
| 預設五色筆顏色      | 5 色塊初始顏色                         | 黑紅藍綠橘   |
| 啟動畫布模式        | 新畫布或繼續上次                       | 新畫布       |
| 預設畫布大小        | 新畫布初始尺寸                         | 1920 × 1080  |
| 繪畫解析度倍率      | 1.0 = 全解析度；0.5 = 效能模式         | 1.0          |
| 時區                | 匯出檔名時間戳用 IANA 時區             | Asia/Taipei  |
| 自動同步            | 定時從 Vault 重新載入 `.enote`         | 關閉         |
| 定時自動儲存        | 定時自動儲存到 `.enote`                | 關閉         |
| 儲存資料夾          | 匯出 PNG 及 `.enote` 的位置            | EasyNote     |
| Google Drive 同步   | 備份/同步至 Google Drive               | 關閉         |

## .enote 檔案格式

`.enote` 是 EasyNote 的專案格式，保存畫布、繪畫、圖片、文字、Markdown 圖層。

### 在 Obsidian 檔案總管顯示 .enote

Obsidian 預設會隱藏未知副檔名。若要顯示 `.enote`：

> **Settings → Files & Links → Detect all file extensions → 開啟**

## 安裝

### 手動安裝
1. 下載 `main.js`、`manifest.json`、`styles.css`（[Releases](../../releases)）
2. 複製到 Vault 的 `.obsidian/plugins/easynote/` 資料夾
3. 在 Obsidian 設定 → 社群插件 啟用 **Easy Note**

### 原始碼建置
```bash
git clone <repo-url>
cd easynote
npm install
npm run build
```
